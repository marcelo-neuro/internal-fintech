## 📌 Business Overview
This project is the core business of an internal corporate bank. It allows companies to offer financial services directly to their employees, working to retain talent and promote financial health. The system manages digital wallets, fee-free internal transfers and a credit granting engine (Loans).

## 🚀 Main Features
* **Wallet Management:** Each user has at least one digital wallet linked to their account to receive deposits and payments.
* **ACID Transaction Engine:** Secure transfers between users with strict balance validations and concurrency, using `BigDecimal` to avoid floating-point rounding errors, and `@Version` to manage concurrency.
* **Extensible Loan Engine:** Dynamic interest calculation based on loan type (PERSONAL, PAYROLL) using the **Strategy Design Pattern**. The approved amount is automatically credited to the user's wallet.
* **Stateless Security:** Stateless authentication with **JSON Web Token (JWT)**
* **Ownership Validation:** The system extracts the user's identity directly from the security context preventing **IDOR (Insecure Direct Object Reference)** attacks and **ID Enumeration** by strategically returning `404 Not Found`.

## 🛠️ Architecture and Technologies
The project is developed focusing on **Clean Code**, **SOLID** and modern architectural patterns.
* **Java 21 / Spring Boot 4.0**
* **Spring Security + Auth0 JWT:** For endpoints protection and token generation.
* **Spring Data JPA / Hibernate:** Object-relational mapping with optimized relationships (Lazy Loading).
* **PostgreSQL:** Relational database.
* **Springdoc OpenAPI (Swagger):** Interactive API documentation.
* **Global Exception Handling:** Standardization of API errors using `@RestControllerAdvice` (RFC 7807 Standard Error Responses).
* **Applied Design Patterns:** Strategy, Factory, Adapter, DTO (Records).

## 🧪 Testing Strategy & Quality Assurance
To ensure enterprise-level reliability, the core business logic is heavily covered by automated unit tests using **JUnit 5** and **Mockito**, strictly following the **AAA (Arrange, Act, Assert)** pattern:
* **Pure Domain Tests:** Design patterns (like Strategy) are tested in isolation focusing on mathematical accuracy using `BigDecimal.compareTo()` to prevent scale-related bugs.
* **Behavior & State Verification:** Tests ensure not only that in-memory states mutate correctly, but also that the Service layer orchestrates the Repositories properly (`verify()`).
* **Sad Paths & Edge Cases:** Robust exception testing to guarantee that transactional boundaries are respected (e.g., ensuring `save()` is `never()` called when a balance validation fails).

## ⚙️ How to run the project locally

**Prerequisites:**
* Java 21+ installed.
* Docker and Docker Compose (to run the database easily).
* Maven.

**Step by step:**
1. Clone this repository:
   ```bash
   git clone https://github.com/marcelo-neuro/internal-fintech.git
   ```
2. Start the PostgreSQL database using Docker Compose:
   ```bash
   docker-compose -f docker-compose-db.yml up -d
   ```

4. Configure your database credentials in the file: `src/main/resources/application.properties`:
   ```properties
   spring.datasource.url=jdbc:postgresql://localhost:5432/fintech_db
   spring.datasource.username=your_username
   spring.datasource.password=your_password
   ```

5. In the project root, run Maven to download the dependencies and start the application:
   ```bash
   ./mvnw spring-boot:run
   ```

## 📚 API Documentation (Swagger)
